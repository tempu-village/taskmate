# TaskMate GitHub Issue template

Use only the sections needed by the Issue. Keep the English section canonical and first. Do not alternate languages line by line.

```markdown
# P{priority}: English issue title

> English is canonical. The folded Japanese section is an AI-generated reference translation and has not been fully reviewed by a human.

## Summary

Canonical English summary.

## Background

Canonical English context and rationale.

## Requirements

- Every normative requirement.

## Acceptance criteria

- Every observable completion condition.

## Verification

- Every required verification step.

## Out of scope

- Every explicit boundary.

---

<details>
<summary>日本語参考訳</summary>

> この日本語版は英語原本を基にAIで作成されています。人間による全文確認は完了していません。

## 概要

> 対応範囲：英語版「Summary」の要約

英語版の決定内容を保った短い概要。

## 背景

> 対応範囲：英語版「Background」の要約

採用理由と重要な制約を保った要約。

## 要件

> 対応範囲：英語版「Requirements」の全項目

- 英語版のすべての要件を、意味を変えずに記載する。

## 受け入れ条件

> 対応範囲：英語版「Acceptance criteria」の全項目

- 英語版のすべての完了条件を記載する。

## 検証方法

> 対応範囲：英語版「Verification」の全項目

- 英語版のすべての検証手順を記載する。

## 対象外

> 対応範囲：英語版「Out of scope」の全項目

- 英語版のすべての境界を記載する。

</details>
```

If an English section is omitted because it is irrelevant, omit its Japanese counterpart. If a Japanese section is condensed beyond full coverage, label it `要約` rather than `全項目`.
