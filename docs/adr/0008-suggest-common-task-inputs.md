# ADR 0008: Suggest common task inputs without replacing exact entry

TaskMate offers `今日`, `明日`, `7日後`, and `日付なし` as one-tap date suggestions and up to ten recently saved labels as reusable suggestions. Mobile users otherwise need to open a calendar or keyboard for common values, but the exact date and free-form label inputs remain available so convenience does not restrict what can be recorded; label history changes only after a task is successfully saved, so cancelled edits do not affect future suggestions.
