# Operations

Operations documentation owns repeatable release, recovery, backup, monitoring, incident, and rollback procedures. Keep it actionable and review it when a release path or operational risk changes.

- [Release TaskMate](releasing.md) documents the current release procedure.
- [Install a development build](development-install.md) documents running an unpublished build, including on desktop and Android with Obsidian Sync.
