# Engineering

Human developers and AI share this entry point. Read [features](features/README.md) for each capability's current What and feature-specific How, [specifications](specifications/README.md) for strict technical contracts, and [design](design/README.md) for cross-cutting implementation structure. [Overview](features/overview.md) introduces the product; [verification](design/testing.md) connects contracts to evidence and gaps. [RFCs](rfcs/README.md) hold unsettled proposals and history; [ADRs](adr/README.md) preserve durable decisions.

Features remain the common product authority for [user guides](../user/README.md), regardless of this directory grouping.
