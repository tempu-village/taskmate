# Engineering

Human developers and AI share this entry point. Read [features](features/README.md) for each capability's standalone current What and feature-specific How, [specifications](specifications/README.md) for strict technical contracts, and [design](design/README.md) for cross-cutting implementation structure. [Overview](features/overview.md) introduces the product; [verification](design/testing.md) connects contracts to evidence and gaps. [RFCs](rfcs/README.md) preserve substantial-change proposals and implementation-decision history but do not own current behavior; [ADRs](adr/README.md) preserve durable decisions.

Features remain the common product authority for [user guides](../user/README.md), regardless of this directory grouping.
