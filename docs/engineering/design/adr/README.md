# Architecture Decision Records (ADR)

Each ADR records a hard-to-reverse decision, its context, and its trade-offs. ADRs are historical decisions, not a replacement for the current product contract or implementation guide. New decisions supersede prior ADRs; do not rewrite accepted history.

## 日本語参考

ADRは戻しにくい判断、その背景、trade-offを記録します。現在の製品契約や実装手順の代わりにはなりません。新しい判断で過去のADRを置き換え、承認済み履歴は書き換えません。
