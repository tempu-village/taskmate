# Architecture Decision Records (ADR)

Each ADR records an accepted, hard-to-reverse decision, its context, and its trade-offs. An [RFC](../rfcs/README.md) reviews an unsettled change; a [Feature](../features/README.md) owns the current feature What and How; a [Specification](../specifications/README.md) owns strict normative technical contracts. ADRs preserve why a durable decision was made and do not replace those current authorities. New decisions supersede prior ADRs; do not rewrite accepted history.

## 日本語参考

ADRは採用済みで戻しにくい判断、その背景、trade-offを記録します。未確定案は[RFC](../rfcs/README.md)、現在の機能のWhatとHowは[Feature](../features/README.md)、厳密な技術契約は[Specification](../specifications/README.md)が所有します。ADRはそれらの正本を置き換えません。新しい判断で過去のADRを置き換え、承認済み履歴は書き換えません。
