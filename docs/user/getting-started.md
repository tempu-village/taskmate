# Your first TaskMate task

This tutorial teaches creating, editing and completing one practice Task. Use a disposable Vault with TaskMate enabled. If it is not installed, follow [manual installation](../../README.md#install-from-a-local-build) first. UI names below use English; Japanese equivalents are in the reference section.

## Create and inspect

1. Open Obsidian's command palette and run **TaskMate: Open task list**.
2. Choose **Date → All**, then **+ Add**.
3. Enter `Try TaskMate` as the title and choose **Today**. Leave Project, Priority and Labels unset for this first exercise.
4. Choose **Save**. Expect one Task in the list with today's date. If hidden, clear active filters using the view/task-actions menu.
5. Select the Task title, add a short note, and save. Reopen it to check that the note remains.

## Complete and find again

1. Select the Task's completion checkbox. With default filters, it disappears from the incomplete list.
2. Open the view/task-actions menu (slider icon), choose **Filter**, enable **Include completed tasks**, then **Apply**.
3. Find the completed Task. Clear its completion checkbox to reopen it, or keep it completed.

You have exercised the Task lifecycle. Continue with [filtering and ordering](how-to/filter-and-sort.md), [Steps and Labels](how-to/edit-tasks.md), or optional [source-note import](how-to/import-source-notes.md). These guides link to the full specifications rather than duplicating their rules.

## 日本語参考

<!-- translation-status: ai-translated -->

> 翻訳状態：`ai-translated`。英語版が正本です。

このTutorialでは練習用タスクを1件作成・編集・完了します。使い捨てVaultでTaskMateを有効にしてください。未導入なら先に[手動導入](../../README.md#install-from-a-local-build)を行います。

### 作成して確認する

1. Obsidianのコマンドパレットから **TaskMate: タスク一覧を開く** を実行します。
2. **日付 → すべて** を選び、**＋ 追加**を押します。
3. 件名を`Try TaskMate`、日付を**今日**にします。最初はプロジェクト・優先度・ラベルを空にします。
4. **保存**すると、今日の日付が付いた1件が見えます。隠れていればスライダーアイコンの操作メニューからフィルターを解除します。
5. 件名を選んで短いメモを追加・保存し、開き直して残っていることを確かめます。

### 完了して再表示する

1. 完了チェックを付けます。初期状態では未完了一覧から消えます。
2. スライダーアイコンのメニューから**フィルタ**を開き、**完了済みタスクを表示**を有効にして**適用**します。
3. 完了したタスクを確認します。チェックを外すと未完了へ戻せます。

次は[絞り込みと並べ替え](how-to/filter-and-sort.md)、[StepsとLabels](how-to/edit-tasks.md)、任意の[メモ取り込み](how-to/import-source-notes.md)へ進めます。
