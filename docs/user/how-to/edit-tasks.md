# Edit Tasks, Steps and Labels

Prerequisite: a Task created with [getting started](../getting-started.md).

## Add supporting Steps

Open the Task by its title. In Steps, use **Add**, enter a Step title and optional date, then save the Step. Repeat for another Step. Change completion in the Step list and drag the content area to reorder (hold briefly on touch). Save the parent Task to persist its edited Steps. To remove a Step, open that Step's editor and choose its Delete action.

## Add or choose Labels

Type a Label and use **Add** or Enter after IME composition finishes. Use **Choose** to select existing Labels, then **Confirm selection**. Save the Task. Cancelling the picker keeps the parent draft; cancelling the Task editor discards unsaved changes. Use the overflow control to reveal more than three selected Labels.

## Edit several Tasks

From a result list, open the view/task-actions menu and choose **Select tasks**. Select the intended rows, then **Edit**. For several Tasks, choose only the fields to change; distinguish retaining a value from clearing it. Apply the changes and check any partial-failure notice. Exit selection mode when finished.

## Delete one Task

Open its editor, use **Delete** in the footer and confirm only if the Task should be removed. TaskMate uses Obsidian's trash behavior. For details, see [Task editing](../../engineering/specifications/task-editing.md), [Steps](../../engineering/specifications/task-steps.md) and [Labels](../../engineering/specifications/labels.md).

前提は[初回体験](../getting-started.md)で作成したタスクです。

### ステップを追加する

タスク名から編集画面を開き、Steps欄の追加で件名と任意の日付を入力・保存します。一覧のチェックで完了を変更し、本文をドラッグして並べ替えます。タッチでは少し長押しします。親タスクの保存で確定します。削除は対象Stepの編集画面から行います。

### ラベルを入力・選択する

入力後に追加、またはIME変換終了後のEnterで確定します。選択から既存ラベルを選び、選択を確定してTaskを保存します。ピッカーのキャンセルは親の下書きを維持し、Task編集のキャンセルは未保存変更を破棄します。3件より多い場合は省略表示から展開できます。

### 複数タスクを編集する

一覧の操作メニューからタスク選択へ入り、対象を選んで編集します。変更しない項目と値を消す項目を区別して適用し、一部失敗の通知も確認します。最後に選択モードを終了します。

### 1件削除する

編集画面の下部にある削除を選び、対象を確認して確定します。Obsidianのゴミ箱動作を利用します。詳しい保証は[編集](../../engineering/specifications/task-editing.md)、[Steps](../../engineering/specifications/task-steps.md)、[Labels](../../engineering/specifications/labels.md)を参照してください。
