# Edit Tasks, Steps and Labels

Prerequisite: a Task created with [getting started](../getting-started.md).

## Set a scheduled date and a deadline

Use **Scheduled** for the day you plan to work on the Task and **Deadline** for the hard date it must be finished by. Choose the × in the Deadline field to clear it. They are independent: moving the scheduled date to replan your work keeps the Deadline, and a missed Deadline stays marked as **Deadline passed** in every list until you complete the Task. Clearing one value never removes the other. A Task with only a Deadline stays in Unplanned until you give it a scheduled date.

## Set a time, repeat or reminder

After setting a Date, choose a **Time** and, if the work repeats, a **Repeat** interval such as every 2 weeks. With a Time set, choose a **Reminder**. Checking a repeating Task moves it to its next date instead of completing it. Reminders appear only while Obsidian is open on that device; to also get system notifications, enable **System notifications** in TaskMate settings. Reminders missed while Obsidian was closed are listed when it opens. See [Schedules and reminders](../../engineering/features/schedules-and-reminders.md).

## Add supporting Steps

Open the Task by its title. In Steps, use **Add**, enter a Step title and optional date, then save the Step. Repeat for another Step. Change completion in the Step list and drag the content area to reorder (hold briefly on touch). Save the parent Task to persist its edited Steps. To remove a Step, open that Step's editor and choose its Delete action.

## Add or choose Labels

Type a Label and use **Add** or Enter after IME composition finishes. Use **Choose** to select existing Labels, then **Confirm selection**. Save the Task. Cancelling the picker keeps the parent draft; cancelling the Task editor discards unsaved changes. Use the overflow control to reveal more than three selected Labels.

## Edit several Tasks

From a result list, open the view/task-actions menu and choose **Select tasks**. Select the intended rows, then **Edit**. For several Tasks, choose only the fields to change; distinguish retaining a value from clearing it. Apply the changes and check any partial-failure notice. Exit selection mode when finished.

## Delete one Task

Open its editor, use **Delete** in the footer and confirm only if the Task should be removed. TaskMate uses Obsidian's trash behavior. For details, see [Task editing](../../engineering/features/task-editing.md), [Steps](../../engineering/features/task-steps.md) and [Labels](../../engineering/features/labels.md).

前提は[初回体験](../getting-started.md)で作成したタスクです。

### 予定日と締め切りを設定する

「予定日」には作業する予定の日を、「締め切り」には必ず終える必要がある日を入力します。締め切りは欄の×で解除します。二つは独立しており、計画の見直しで予定日を動かしても締め切りは変わりません。過ぎた締め切りは、タスクを完了するまでどの一覧でも「締め切り超過」と表示されます。片方を解除してももう片方は残ります。締め切りだけのタスクは、予定日を付けるまで未計画に表示されます。

### 時刻・繰り返し・通知を設定する

日付を設定した後に「時刻」を選び、繰り返す作業なら「繰り返し」で2週間ごとなどの間隔を選びます。時刻があれば「通知」を選べます。繰り返しタスクにチェックを入れると、完了せず次の日付へ進みます。通知はその端末でObsidianを開いている間だけ表示します。システム通知も受け取るには、TaskMateの設定で「システム通知」を有効にします。Obsidianを閉じている間に過ぎた通知は、次に開いたときに一覧表示します。

### ステップを追加する

タスク名から編集画面を開き、Steps欄の追加で件名と任意の日付を入力・保存します。一覧のチェックで完了を変更し、本文をドラッグして並べ替えます。タッチでは少し長押しします。親タスクの保存で確定します。削除は対象Stepの編集画面から行います。

### ラベルを入力・選択する

入力後に追加、またはIME変換終了後のEnterで確定します。選択から既存ラベルを選び、選択を確定してTaskを保存します。ピッカーのキャンセルは親の下書きを維持し、Task編集のキャンセルは未保存変更を破棄します。3件より多い場合は省略表示から展開できます。

### 複数タスクを編集する

一覧の操作メニューからタスク選択へ入り、対象を選んで編集します。変更しない項目と値を消す項目を区別して適用し、一部失敗の通知も確認します。最後に選択モードを終了します。

### 1件削除する

編集画面の下部にある削除を選び、対象を確認して確定します。Obsidianのゴミ箱動作を利用します。詳しい保証は[編集](../../engineering/features/task-editing.md)、[Steps](../../engineering/features/task-steps.md)、[Labels](../../engineering/features/labels.md)を参照してください。
